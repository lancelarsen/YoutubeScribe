YouTube Transcript Extractor Documentation

This local app extracts plain transcript text from public YouTube videos. It returns text only and does not include timestamps.

Use The App

  1. Open the app at http://127.0.0.1:5173.
  2. Paste a public YouTube video URL or choose an example URL.
  3. Select Get Transcript.
  4. Copy the transcript or download it as a text file.
  5. Use the theme icon in the app header to switch between light and dark mode.

Supported Links

The app accepts normal watch links, short links, embeds, shorts, and live URLs.

  • https://www.youtube.com/watch?v=VIDEO_ID
  • https://youtu.be/VIDEO_ID
  • https://www.youtube.com/embed/VIDEO_ID
  • https://www.youtube.com/shorts/VIDEO_ID
  • https://www.youtube.com/live/VIDEO_ID

What Extraction Does

The server first tries caption data from the YouTube watch page. If captions are not directly exposed, it launches Playwright, opens the public video page, and reads the visible Transcript panel when YouTube provides one.

Limits

  • The app does not bypass login requirements, private videos, age gates, paywalls, or region restrictions.
  • If YouTube does not expose captions or a Transcript panel, no transcript can be returned.
  • Browser fallback depends on a working local Playwright Chromium install.

Run And Verify

npm install
npm run dev
npm run verify

To force the browser Transcript-panel verification path:

node scripts/verify.mjs --browser "https://www.youtube.com/watch?v=UF8uR6Z6KLc"

API

Send a JSON request to POST /api/transcript.

{
  "url": "https://www.youtube.com/watch?v=aircAruvnKk"
}

Successful responses include text, lines, source, videoId, and optional title and language fields. The source is caption-data or browser-transcript-panel.
